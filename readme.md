# CAMI Consultancy — Advanced Materials & Process Consultancy

A modern, single-page brand website for CAMI, built with semantic HTML5, custom CSS, and vanilla JavaScript.

## Features

- Fully responsive layout (mobile, tablet, desktop)
- Fixed navigation with scroll effect and mobile hamburger menu
- Dynamic project cards rendered from JavaScript data
- Working contact form with client-side validation
- Smooth anchor scrolling
- Intersection Observer fade-in animations
- Brutalist/minimalist aesthetic with monochrome palette
